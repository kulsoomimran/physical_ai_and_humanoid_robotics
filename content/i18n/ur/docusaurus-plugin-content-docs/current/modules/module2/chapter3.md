# باب 9: روبوٹکس شبیہہ سازی کے لیے یونیٹی

## سیکھنے کے اہداف

اس باب کے اختتام تک، آپ درج ذیل کر سکیں گے:
- روبوٹکس شبیہہ سازی کے لیے یونیٹی کی معماری اور صلاحیتیں سمجھنا
- روبوٹکس اطلاقیے کے لیے یونیٹی سیٹ اپ اور ترتیب دینا
- یونیٹی ماحول میں روبوٹ ماڈلز تخلیق اور درآمد کرنا
- یونیٹی میں سینسر شبیہہ سازی اور فزکس ماڈلنگ نافذ کرنا
- حقیقی وقت کی روبوٹکس ترقی کے لیے یونیٹی کو ROS/ROS2 کے ساتھ انضمام کرنا
- کمپیوٹر وژن اطلاقیے کے لیے یونیٹی کی فوٹو ریلسٹک رینڈرنگ کا فائدہ اٹھانا

## 1. روبوٹکس کے لیے یونیٹی کا تعارف

### 1.1 جائزہ اور تاریخ

یونیٹی ایک طاقتور کراس پلیٹ فارم گیم انجن ہے جو یونیٹی ٹیکنالوجیز کے ذریعہ تیار کیا گیا ہے جس نے روبوٹکس شبیہہ سازی اور ترقی میں نمایاں اطلاقیے تلاش کیا ہے۔ اصل میں گیم ترقی کے لیے ڈیزائن کیا گیا، یونیٹی کا مضبوط فزکس انجن، بلند معیار کی رینڈرنگ کی صلاحیتیں، اور لچکدار اسکرپٹنگ ماحول اسے روبوٹکس شبیہہ سازی کے لیے ایک عمدہ انتخاب بناتا ہے، خاص طور پر ان اطلاقیے کے لیے جن کو فوٹو ریلسٹک رینڈرنگ، پیچیدہ ماحول، اور حقیقی وقت کے تعامل کی ضرورت ہو۔

робوٹکس میں یونیٹی کی اپنائی یونیٹی روبوٹکس ٹیم کی ترقی کے ذریعہ مخصوص ٹولز اور پیکجز کے تیار کرنے کی وجہ سے ہوئی ہے جو گیم ترقی اور روبوٹکس اطلاقیے کے درمیان خلاء کو پاٹتا ہے۔

### 1.2 کلیدی خصوصیات اور صلاحیتیں

یونیٹی روبوٹکس اطلاقیے کے لیے کئی کلیدی خصوصیات پیش کرتا ہے جو اسے قیمتی بناتا ہے:

- **فوٹو ریلسٹک رینڈرنگ**: فزیکلی بیسڈ میٹریلز کے ساتھ اعلیٰ درجہ کی رینڈرنگ پائپ لائن
- **لچکدار فزکس انجن**: قابل ترتیب پیرامیٹرز کے ساتھ تیار کردہ فزکس شبیہہ سازی
- **کراس-پلیٹ فارم ڈیپلائمنٹ**: ڈیسک ٹاپ، موبائل، اور ایمبیڈیڈ سسٹم سمیت متعدد پلیٹ فارمزم پر ڈیپلائمنٹ
- **ایسٹ سٹور**: 3D ماڈلز، ماحول، اور ٹولز کی وسیع لائبریری
- **اسکرپٹنگ ماحول**: حقیقی وقت کے انجام کے ساتھ C# اسکرپٹنگ
- **VR/AR حمایت**: ورچوئل اور اضافی حقیقت کے اطلاقیے کے لیے براہ راست حمایت

## 2. یونیٹی روبوٹکس ہب اور ROS انضمام

### 2.1 یونیٹی روبوٹکس ہب

یونیٹی روبوٹکس ہب ایک جامع پیکج ہے جو فراہم کرتا ہے:

- **ROS-TCP-Connector**: یونیٹی اور ROS/ROS2 کے درمیان رابطہ پل
- **Unity-Robotics-Helpers**: روبوٹکس-مخصوص کاموں کے لیے یوٹیلیٹیز
- **نمونہ ماحول**: پہلے سے تیار روبوٹکس شبیہہ سازی کے ماحول
- **دستاویزات اور ٹیوٹوریلز**: روبوٹکس ترقی کے لیے جامع گائیڈز

### 2.2 ROS/ROS2 انضمام معماری

یونیٹی TCP/IP رابطہ لیئر کے ذریعے ROS/ROS2 کے ساتھ انضمام کرتا ہے:

```
[یونیٹی ایپلیکیشن] <-> [ROS-TCP-Connector] <-> [ROS/ROS2 نوڈس]
```

یہ معماری یونیٹی کو اجازت دیتا ہے:
- ROS ٹوپکس کو شائع اور سبسکرائب کرنا
- ROS سروسز کال کرنا
- کسٹم پیغام کی اقسام کا تبادلہ کرنا
- شبیہہ سازی کا وقت ROS وقت کے ساتھ ہم آہنگ کرنا

### 2.3 رابطہ پروٹوکولز

یونیٹی روبوٹکس انضمام کے لیے متعدد رابطہ پروٹوکولز کی حمایت کرتا ہے:

- **ROS TCP پروٹوکول**: معیاری TCP-پر مبنی رابطہ
- **ROS برج پروٹوکول**: JSON-پر مبنی پیغام کا تبادلہ
- **کسٹم پروٹوکولز**: صارف-تعریف شدہ رابطہ کے طریقے

## 3. روبوٹکس پروجیکٹس کے لیے یونیٹی کا قیام

### 3.1 انسٹالیشن اور ضروریات

4. **ROS/ROS2 ماحول**: مناسب طریقے سے تشکیل شدہ ROS/ROS2 انسٹالیشن

## 4. روبوٹ ماڈلز تخلیق اور درآمد کرنا

### 4.1 روبوٹ ماڈل درآمد کا عمل

یونیٹی میں روبوٹ ماڈلز کو درآمد کرنا شامل کرتا ہے:

1. **ماڈل فارمیٹ**: FBX، OBJ، DAE، اور دیگر 3D فارمیٹس کی حمایت
2. **کوآرڈینیٹ سسٹم تبدیلی**: URDF/SDF سے یونیٹی کوآرڈینیٹ سسٹم میں
3. **جوائنٹ کی ترتیب**: جسمانی جوائنٹس کو یونیٹی کمپوننٹس میں میپ کرنا
4. **میٹریل اور ٹیکسچر درآمد**: وژوئل خصوصیات کو محفوظ کرنا

### 4.2 URDF سے یونیٹی تبدیلی

یونیٹی URDF ماڈلز کو تبدیل کرنے کے لیے ٹولز فراہم کرتا ہے:

- **URDF-Importer پیکج**: URDF کو یونیٹی ماڈلز میں خودکار تبدیلی
- **جوائنٹ میپنگ**: ریوولوٹ، پرائز میٹک، اور فکسڈ جوائنٹس کی مناسب میپنگ
- **جسمانی خصوصیات**: ماس، اینرشیا، اور فرکشن پیرامیٹرز کی تبدیلی
- **ویژوئل اور کالیژن میشز**: ویژوئل اور کالیژن جیومیٹری کا علیحدہ ہینڈلنگ

### 4.3 یونیٹی میں روبوٹ کی ترتیب

یونیٹی میں روبوٹس کی ترتیب کی ضرورت ہے:

- **Rigidbody کمپوننٹس**: فزکس شبیہہ سازی کے لیے
- **جوائنٹ کمپوننٹس**: ہنگ، سلائیڈر، اور قابل ترتیب جوائنٹس
- **کولائیڈرز**: میش، باکس، سپیئر، اور کیپسول کولائیڈرز
- **.Center of Mass**: مناسب ماس تقسیم کا قیام

## 5. یونیٹی میں سینسر شبیہہ سازی

### 5.1 کیمرہ اور وژن سینسرز

یونیٹی جامع کیمرہ شبیہہ سازی فراہم کرتا ہے:

- **RGB کیمرے**: مناسب پیرامیٹرز کے ساتھ معیاری رنگ کے کیمرے
- **ڈیپتھ کیمرے**: ڈیپتھ معلومات کی تیاری
- **سٹیریو کیمرے**: سٹیریو وژن سیٹ اپ
- **LiDAR شبیہہ سازی**: رے کاسٹنگ سے پوائنٹ کلاؤڈ کی تیاری
- **تصویر کیپچر**: بلند ریزولوشن تصویر کیپچر کی صلاحیتیں

### 5.2 کیمرہ کی ترتیب

روبوٹکس اطلاقیے کے لیے یونیٹی میں کیمرہ سیٹ اپ کی مثال:

```csharp
using UnityEngine;
using Unity.Robotics.ROSTCPConnector;
using RosMessageTypes.Sensor;

public class CameraPublisher : MonoBehaviour
{
    public Camera camera;
    private ROSConnection ros;
    private string topicName = "camera/image_raw";

    void Start()
    {
        ros = ROSConnection.GetOrCreateInstance();
    }

    void Update()
    {
        // تصویر کو کیپچر کریں اور ROS ٹوپک پر شائع کریں
        Texture2D image = new Texture2D(camera.pixelWidth, camera.pixelHeight, TextureFormat.RGB24, false);
        RenderTexture currentRT = RenderTexture.active;
        RenderTexture.active = camera.targetTexture;
        camera.Render();
        image.ReadPixels(new Rect(0, 0, camera.pixelWidth, camera.pixelHeight), 0, 0);
        image.Apply();
        RenderTexture.active = currentRT;

        // تبدیل کریں اور تصویر کو ROS پر شائع کریں
        sensor_msgs.ImageMsg rosImage = ImageConversion.GetImageMessage(image, camera);
        ros.Publish(topicName, rosImage);
    }
}
```

### 5.3 فزکس-مبنی سینسر شبیہہ سازی

یونیٹی فزکس-مبنی سینسر شبیہہ سازی کو فعال کرتا ہے:

- **رے کاسٹنگ**: LiDAR اور قریبی سینسرز کے لیے
- **Physics.RaycastAll**: متعدد چیزوں کا پتہ لگانا
- **ٹرگر کولائیڈرز**: قریبی اور رابطہ کا پتہ لگانا
- **فورس سینسرز**: جوائنٹ فورس اور ٹورک ماپ

## 6. فزکس شبیہہ سازی اور ماحول ماڈلنگ

### 6.1 فزکس انجن کی ترتیب

یونیٹی کا فزکس انجن روبوٹکس اطلاقیے کے لیے تشکیل دیا جا سکتا ہے:

- **گریویٹی ترتیبات**: مختلف ماحول کے لیے قابل ایڈجسٹ گریویٹی
- **solver iterations**: درستگی بمقابلہ کارکردگی کے تنازعات
- **کالیژن ڈیٹیکشن**: ڈسکریٹ بمقابلہ جاری کالیژن ڈیٹیکشن
- **فزکس میٹریلز**: کسٹم فرکشن اور باؤنس کی خصوصیات

### 6.2 ماحول کی تخلیق

یونیٹی میں حقیقی ماحول تخلیق کرنا:

- **ٹیرین ٹولز**: بڑے پیمانے پر باہر کے ماحول
- **ProBuilder**: سادہ ماحول کی جلدی پروٹو ٹائپنگ
- **ایسٹ امپورٹ**: CAD ماڈلز اور پیچیدہ جیومیٹریز کو درآمد کرنا
- **لائٹنگ سیٹ اپ**: حقیقی لائٹنگ کی شرائط

### 6.3 کارکردگی کی بہتری

فزکس شبیہہ سازی کی کارکردگی کو بہتر بنانا:

- **تفصیل کی سطح (LOD)**: فاصلے پر جیومیٹری کی پیچیدگی کو کم کرنا
- **اکلوژن کلینگ**: کیمرے کے نظارے سے چھپی چیزوں کو چھپانا
- **لائٹنگ کا بیک کرنا**: سٹیٹک لائٹنگ کا پیشتر حساب
- **آبجیکٹ پولنگ**: فزکس آبجیکٹس کو موثر طریقے سے دوبارہ استعمال کرنا

## 7. ROS/ROS2 انضمام نفاذ

### 7.1 پیغام کی قسم کی وضاحت

یونیٹی کسٹم ROS پیغام کی اقسام کی حمایت کرتا ہے:

```csharp
// مثال کسٹم پیغام کی وضاحت
namespace RosMessageTypes.Custom
{
    public class RobotStateMsg : Message
    {
        public const string k_RosMessageName = "custom_msgs/RobotState";
        public override string RosMessageName => k_RosMessageName;

        public float[] joint_positions;
        public float[] joint_velocities;
        public float[] joint_efforts;

        public RobotStateMsg()
        {
            this.joint_positions = new float[0];
            this.joint_velocities = new float[0];
            this.joint_efforts = new float[0];
        }
    }
}
```

### 7.2 شائع کنندہ اور سبسکرائیبر نفاذ

یونیٹی میں ROS رابطہ نافذ کرنا:

```csharp
using Unity.Robotics.ROSTCPConnector;
using RosMessageTypes.Std;

public class RobotController : MonoBehaviour
{
    private ROSConnection ros;
    private string robotCommandTopic = "robot/command";

    void Start()
    {
        ros = ROSConnection.GetOrCreateInstance();
        ros.RegisterPublisher<UInt8Msg>(robotCommandTopic);
    }

    public void SendCommand(byte command)
    {
        ros.Publish(robotCommandTopic, new UInt8Msg(command));
    }
}
```

- **ایکشن کلائنٹس**: ایسکرونوس گول-مبنی رابطہ

## 8. کمپیوٹر وژن اطلاقیے

### 8.1 مصنوعی ڈیٹا تیاری

کمپیوٹر وژن کے لیے مصنوعی ڈیٹا تیاری میں یونیٹی عمدہ ہے:

- **فوٹو ریلسٹک رینڈرنگ**: بلند معیار کے مصنوعی تصاویر
- **ڈومین رینڈمائزیشن**: لائٹنگ، ٹیکسچرز، اور پس منظر کو مختلف کرنا
- **گراؤنڈ ٹروتھ تیاری**: مصنوعی ڈیٹا کی خودکار توثیق
- **ڈیٹا سیٹ پائپ لائن**: خودکار ڈیٹا سیٹ تیاری ورک فلو

### 8.2 ڈومین رینڈمائزیشن کی تکنیکیں

یونیٹی میں ڈومین رینڈمائزیشن نافذ کرنا:

- **میٹریل ویریئیشن**: ٹیکسچرز اور میٹریلز کو رینڈمائز کرنا
- **لائٹنگ ویریئیشن**: لائٹنگ کی شرائط کو تبدیل کرنا
- **کیمرہ پیرامیٹرز**: فوکل لمبائی اور سینسر کی خصوصیات کو مختلف کرنا
- **ماحولی تبدیلیاں**: پس منظر اور سیاق و سباق کو تبدیل کرنا

### 8.3 تربیت ڈیٹا پائپ لائن

تربیت ڈیٹا پائپ لائنیں تخلیق کرنا:

1. **منظر تیاری**: خودکار ماحول کی تخلیق
2. **چیز کی جگہ**: رینڈمائز چیز کی پوزیشننگ
3. **تصویر کیپچر**: زیادہ پیداواریت کے ساتھ تصویر کیپچر
4. **توثیق**: خودکار گراؤنڈ ٹروتھ تیاری
5. **ایکسپورٹ**: ML فریم ورکس کے لیے ڈیٹا سیٹ کی فارمیٹنگ

## 9. متعدد روبوٹ شبیہہ سازی

### 9.1 متعدد ایجنٹ معماری

یونیٹی متعدد روبوٹ شبیہہ سازی کی حمایت کرتا ہے مندرجہ ذیل کے ذریعے:

- **Prefab سسٹم**: دوبارہ استعمال کے قابل روبوٹ ٹیمپلیٹس
- **نیٹ ورک رابطہ**: متعدد ایجنٹ کی ہم آہنگی
- **مشترکہ ماحول**: عام شبیہہ سازی کی جگہیں
- **وسیلے کا نظم**: موثر میموری اور حساب کا استعمال

### 9.2 ہم آہنگی اور رابطہ

متعدد روبوٹ ہم آہنگی نافذ کرنا:

- **رابطہ پروٹوکولز**: روبوٹ-سے-روبوٹ پیغام رسانی
- **کام کی تقسیم**: تقسیم شدہ کام کا نظم
- **کالیژن ایوائیڈنس**: متعدد ایجنٹ راستہ کی منصوبہ بندی

## 10. کارکردگی کی بہتری اور بہترین مشقیں

### 10.1 رینڈرنگ کی بہتری

روبوٹکس کے لیے رینڈرنگ کی کارکردگی کو بہتر بنانا:

- **مستقل ٹائم سٹیپ**: مسلسل فزکس شبیہہ سازی

### 10.2 شبیہہ سازی کی درستگی

شبیہہ سازی کی درستگی یقینی بنانا:

- **فزکس پیرامیٹر ٹیوننگ**: حقیقی دنیا کے رویے سے میل
- **سینسر کیلیبریشن**: درست سینسر شبیہہ سازی
- **وقت ہم آہنگی**: ROS کے ساتھ مناسب وقت
- **توثیق کے طریقے**: حقیقی دنیا کے ڈیٹا کے ساتھ موازنہ

### 10.3 ترقی کا ورک فلو

یونیٹی روبوٹکس ترقی کے لیے تجویز کردہ ورک فلو:

1. **سادگی سے شروع کریں**: بنیادی ماڈلز اور فعالیت کے ساتھ شروع کریں
2. **تدریجی ترقی**: پیچیدگی کو تدریج سے بڑھائیں
3. **توثیق**: حقیقی دنیا کے ڈیٹا کے ساتھ مسلسل موازنہ
4. **بہتری**: ضروریات کی بنیاد پر کارکردگی ٹیوننگ
5. **دستاویزات**: تعاون کے لیے واضح دستاویزات برقرار رکھیں

## 11. اعلیٰ درجہ کے موضوعات

### 11.1 مشین لرننگ انضمام

یونیٹی مضبوط لرننگ کے لیے ML-Agents ٹول کٹ فراہم کرتا ہے:

- **مضبوط لرننگ**: شبیہہ سازی میں روبوٹس کو تربیت دینا
- **بیhevior cloning**: نظاہر سے سیکھنا
- **imitation learning**: ماہر رویے کو نقل کرنا
- **transfer learning**: شبیہہ سازی-سے-سیکھے ہوئے ماڈلز کو حقیقی روبوٹس پر لاگو کرنا

### 11.2 ہارڈ ویئر-ان-د-لُوپ شبیہہ سازی

یونیٹی ہارڈ ویئر-ان-د-لُوپ سیٹ اپس کی حمایت کرتا ہے:

- **حقیقی سینسر انضمام**: حقیقی سینسرز کو شبیہہ سازی سے منسلک کرنا
- **حقیقی ایکچویٹر کنٹرول**: شبیہہ سازی سے حقیقی ایکچویٹرز کو کنٹرول کرنا
- **مکسڈ ریلٹی**: حقیقی اور مجازی عناصر کو جوڑنا
- **سیفٹی سسٹم**: ہارڈ ویئر کے محفوظ کام کو یقینی بنانا

### 11.3 کلاؤڈ-مبنی شبیہہ سازی

یونیٹی کلاؤڈ-مبنی روبوٹکس شبیہہ سازی کو فعال کرتا ہے:

- **تقسیم شدہ کمپیوٹنگ**: کلاؤڈ انفراسٹرکچر پر شبیہہ سازی چلانا
- **کنٹینرائزیشن**: شبیہہ سازی کے ماحول کے لیے ڈوکر کنٹینرز
- **scalability**: متعدد متوازی شبیہہ سازی چلانا
- **ریموٹ رسائی**: کہیں سے بھی شبیہہ سازی تک رسائی

## 12. باب کا خلاصہ

یونیٹی اس کی فوٹو ریلسٹک رینڈرنگ کی صلاحیتیں، لچکدار فزکس انجن، اور مضبوط ROS انضمام کے ساتھ روبوٹکس شبیہہ سازی کے لیے ایک طاقتور پلیٹ فارم فراہم کرتا ہے۔ اس کی کمپیوٹر وژن اطلاقیے کے لیے مصنوعی ڈیٹا تیار کرنے کی صلاحیت، اس کے گیم انجن کی صلاحیتیں کے ساتھ مل کر، Gazebo جیسے فزکس-مرکز شبیہہ سازی کے لیے ایک عمدہ اضافہ ثابت ہوتا ہے۔ یونیٹی کی معماری، ترتیب، اور انضمام کے نمونے کو سمجھنا روبوٹکس ترقی میں اس کی صلاحیتوں کا فائدہ اٹھانے کے لیے ضروری ہے۔

## 13. اگلے اقدامات

اگلا باب فزکس شبیہہ سازی اور کالیژن ڈیٹیکشن کو تلاش کرے گا، اس باب اور پچھلے باب میں متعارف کرائے گئے شبیہہ سازی کے ماحول کی بنیاد پر۔ ہم یہ مطالعہ کریں گے کہ حقیقی فزکس کے رویے اور کالیژن ڈیٹیکشن سسٹم کیسے نافذ کریں جو Gazebo اور یونیٹی-مبنی روبوٹکس شبیہہ سازی کے لیے اہم ہیں۔
